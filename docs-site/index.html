Welcome to MaleficMobile

A comprehensive Kotlin Multiplatform template designed for UI developers who want to quickly build functional mobile applications with Compose Multiplatform.

Why MaleficMobile?

  • Cross-Platform: Write once, run on both Android and iOS
  • Modern UI: Built with Compose Multiplatform and Material 3
  • Developer-Friendly: Pre-configured with best practices and examples
  • Production-Ready: Includes theming, navigation, and architecture patterns

Mobile-First

Optimized for mobile development with responsive design patterns

Fast Development

Get started in minutes with pre-configured project structure

Modular

Easily extensible architecture for growing applications

Getting Started

Follow these step-by-step instructions to set up your development environment and run your first MaleficMobile app.

1

Clone the Repository

First, clone the MaleficMobile template repository to your local machine:

git clone https://github.com/OmyDaGreat/MaleficMobile.git
cd MaleficMobile
Tip: You can also fork the repository to make it your own project.
2

Open in IntelliJ IDEA

Launch IntelliJ IDEA and open the project:

  1. Open IntelliJ IDEA
  2. Click Open or File → Open
  3. Navigate to and select the MaleficMobile folder
  4. Click OK to open the project
  5. Wait for Gradle to sync (this may take a few minutes on first run)
Note: The first sync may take several minutes as Gradle downloads dependencies.
3

Configure Android Emulator

Set up an Android Virtual Device (AVD) to test your app:

  1. In IntelliJ IDEA, go to View → Tool Windows → Device Manager
  2. Click the + button or Create Device
  3. Choose a device definition (e.g., Pixel 4 or Pixel 6)
  4. Select a system image:
    • Recommended: Latest API level with x86_64 or ARM64
    • Google APIs or Google Play versions are preferred
  5. Configure AVD settings and click Finish
Common Issues:
  • AMD CPU: Enable SVM mode in BIOS
  • Linux: Install QEMU and libvirt for hardware acceleration
  • Windows: Enable Hyper-V or HAXM
  • Slow emulator: Ensure hardware acceleration is enabled
4

Build and Run

Now let's build and run your first MaleficMobile app:

  1. Start your Android emulator from Device Manager
  2. In the project tree, navigate to: composeApp/src/androidMain/kotlin/com/jetbrains/kmpapp/
  3. Open MainActivity.kt
  4. Click the green play button next to class MainActivity
  5. Select your running emulator from the dropdown
  6. Wait for the app to build and install
Success! You should now see the MaleficMobile app running in your emulator.

Project Structure

Understanding the project structure is crucial for effective development. MaleficMobile follows Kotlin Multiplatform conventions with a clear separation of platform-specific and shared code.

MaleficMobile/
├── 📁 composeApp/                    # Main KMP module
│   └── 📁 src/
│       ├── 📁 androidMain/           # Android-specific code
│       │   └── 📁 kotlin/com/jetbrains/kmpapp/
│       │       ├── 📄 MainActivity.kt      # Android entry point
│       │       └── 📄 MobileApp.kt         # Application class
│       ├── 📁 iosMain/               # iOS-specific code  
│       │   └── 📁 kotlin/com/jetbrains/kmpapp/
│       │       └── 📄 MainViewController.kt # iOS entry point
│       └── 📁 commonMain/            # Shared code (Android + iOS)
│           └── 📁 kotlin/com/jetbrains/kmpapp/
│               ├── 📄 App.kt               # Root Composable
│               └── 📁 screens/
│                   ├── 📄 EmptyScreen.kt   # Example screen
│                   └── 📄 DemoScreen.kt    # Demo screen
├── 📁 iosApp/                        # iOS app wrapper
│   └── 📁 iosApp/
│       ├── 📄 ContentView.swift           # SwiftUI bridge
│       └── 📄 iOSApp.swift               # iOS app entry
└── 📄 build.gradle.kts               # Root build script

composeApp/

The heart of your application. This Kotlin Multiplatform module contains all shared business logic and UI code.

  • commonMain: Code that runs on both platforms
  • androidMain: Android-specific implementations
  • iosMain: iOS-specific implementations

iosApp/

Native iOS application wrapper written in SwiftUI that hosts the shared Compose UI.

  • Minimal Swift code
  • Bridges to KMP module
  • Handles iOS-specific app lifecycle

Key Files Explained:

App.kt
Main Composable function that defines your app's UI tree and theme.
MainActivity.kt
Android Activity that hosts the Compose content using setContent.
MainViewController.kt
iOS UIViewController that wraps Compose UI for iOS consumption.
EmptyScreen.kt
Simple example screen showing basic Compose UI structure.
DemoScreen.kt
Interactive demo screen with state management examples.

Customizing Your App

Now that you have the app running, let's customize it to make it your own. We'll cover the most common customizations step by step.

1. Change App Name & Icon

Personalize your app with a custom name and icon.

App Name

Edit the Android manifest file:

<!-- composeApp/src/androidMain/AndroidManifest.xml -->
<application
    android:name=".MobileApp"
    android:label="Your App Name"  <-- Change this
    ...>

App Icon

Replace icon files in these directories:

  • composeApp/src/androidMain/res/mipmap-hdpi/
  • composeApp/src/androidMain/res/mipmap-mdpi/
  • composeApp/src/androidMain/res/mipmap-xhdpi/
  • composeApp/src/androidMain/res/mipmap-xxhdpi/
  • composeApp/src/androidMain/res/mipmap-xxxhdpi/
Tip: Use Android Studio's Image Asset Studio to generate icons in all required sizes.

2. Update Colors & Theme

Customize your app's visual appearance with Material 3 theming.

Open App.kt and modify the MaterialTheme:

@Composable
fun App() {
    MaterialTheme(
        colorScheme = if (isSystemInDarkTheme()) {
            darkColorScheme(
                primary = Color(0xFF6366F1),      // Indigo
                secondary = Color(0xFF10B981),    // Emerald
                background = Color(0xFF0F172A),   // Dark background
            )
        } else {
            lightColorScheme(
                primary = Color(0xFF4F46E5),      // Indigo
                secondary = Color(0xFF059669),    // Emerald  
                background = Color(0xFFFAFAFA),   // Light background
            )
        }
    ) {
        // Your app content
    }
}
Key Color Roles:
  • Primary: Main brand color
  • Secondary: Accent color
  • Background: App background
  • Surface: Card/container backgrounds
  • OnPrimary/OnSecondary: Text colors on colored surfaces

Use the Material Theme Builder to generate complete color schemes.

Simple Counter App

A basic counter demonstrating state management in Compose:

@Composable
fun CounterScreen(modifier: Modifier = Modifier) {
    var count by remember { mutableStateOf(0) }
    
    Column(
        modifier = modifier.padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        Text(
            text = "Count: $count",
            style = MaterialTheme.typography.headlineLarge
        )
        
        Spacer(modifier = Modifier.height(16.dp))
        
        Row(
            horizontalArrangement = Arrangement.spacedBy(8.dp)
        ) {
            Button(
                onClick = { count-- },
                enabled = count > 0
            ) {
                Text("-")
            }
            
            Button(onClick = { count++ }) {
                Text("+")
            }
        }
        
        if (count > 10) {
            Text(
                text = "Wow, that's a lot!",
                color = MaterialTheme.colorScheme.primary,
                style = MaterialTheme.typography.bodyLarge
            )
        }
    }
}

Form Input Handling

Collecting and validating user input with proper state management:

@Composable
fun UserFormScreen(modifier: Modifier = Modifier) {
    var name by remember { mutableStateOf("") }
    var email by remember { mutableStateOf("") }
    var isValid by remember { mutableStateOf(false) }
    
    LaunchedEffect(name, email) {
        isValid = name.isNotBlank() && 
                  email.contains("@") && 
                  email.contains(".")
    }
    
    Column(
        modifier = modifier.padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        OutlinedTextField(
            value = name,
            onValueChange = { name = it },
            label = { Text("Full Name") },
            modifier = Modifier.fillMaxWidth()
        )
        
        OutlinedTextField(
            value = email,
            onValueChange = { email = it },
            label = { Text("Email Address") },
            keyboardOptions = KeyboardOptions(
                keyboardType = KeyboardType.Email
            ),
            modifier = Modifier.fillMaxWidth()
        )
        
        Button(
            onClick = { /* Handle form submission */ },
            enabled = isValid,
            modifier = Modifier.fillMaxWidth()
        ) {
            Text("Submit")
        }
    }
}

Dynamic List with Actions

Managing lists of data with add/remove functionality:

data class TodoItem(
    val id: Int,
    val text: String,
    val completed: Boolean = false
)

@Composable
fun TodoListScreen(modifier: Modifier = Modifier) {
    var todos by remember { 
        mutableStateOf(listOf()) 
    }
    var newTodoText by remember { mutableStateOf("") }
    
    Column(modifier = modifier.padding(16.dp)) {
        // Add new todo
        Row(
            modifier = Modifier.fillMaxWidth(),
            verticalAlignment = Alignment.CenterVertically
        ) {
            OutlinedTextField(
                value = newTodoText,
                onValueChange = { newTodoText = it },
                placeholder = { Text("Add a task...") },
                modifier = Modifier.weight(1f)
            )
            
            IconButton(
                onClick = {
                    if (newTodoText.isNotBlank()) {
                        todos = todos + TodoItem(
                            id = todos.size,
                            text = newTodoText
                        )
                        newTodoText = ""
                    }
                }
            ) {
                Icon(Icons.Default.Add, "Add")
            }
        }
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // Todo list
        LazyColumn(
            verticalArrangement = Arrangement.spacedBy(8.dp)
        ) {
            items(todos, key = { it.id }) { todo ->
                TodoItemCard(
                    todo = todo,
                    onToggle = { todoId ->
                        todos = todos.map {
                            if (it.id == todoId) {
                                it.copy(completed = !it.completed)
                            } else it
                        }
                    },
                    onDelete = { todoId ->
                        todos = todos.filter { it.id != todoId }
                    }
                )
            }
        }
    }
}

Making Network Requests

Fetching data from APIs with proper loading states:

sealed class UiState {
    object Loading : UiState()
    data class Success(val data: T) : UiState()
    data class Error(val exception: Throwable) : UiState()
}

@Composable
fun DataScreen(modifier: Modifier = Modifier) {
    var uiState by remember { 
        mutableStateOf>>(UiState.Loading) 
    }
    
    LaunchedEffect(Unit) {
        try {
            // Simulate network call
            delay(2000)
            val data = listOf("Item 1", "Item 2", "Item 3")
            uiState = UiState.Success(data)
        } catch (e: Exception) {
            uiState = UiState.Error(e)
        }
    }
    
    Box(
        modifier = modifier.fillMaxSize(),
        contentAlignment = Alignment.Center
    ) {
        when (val state = uiState) {
            is UiState.Loading -> {
                Column(horizontalAlignment = Alignment.CenterHorizontally) {
                    CircularProgressIndicator()
                    Spacer(modifier = Modifier.height(8.dp))
                    Text("Loading data...")
                }
            }
            
            is UiState.Success -> {
                LazyColumn {
                    items(state.data) { item ->
                        ListItem(
                            headlineContent = { Text(item) }
                        )
                    }
                }
            }
            
            is UiState.Error -> {
                Column(horizontalAlignment = Alignment.CenterHorizontally) {
                    Icon(
                        Icons.Default.Error,
                        contentDescription = null,
                        tint = MaterialTheme.colorScheme.error
                    )
                    Text(
                        text = "Failed to load data",
                        color = MaterialTheme.colorScheme.error
                    )
                    Button(
                        onClick = { uiState = UiState.Loading }
                    ) {
                        Text("Retry")
                    }
                }
            }
        }
    }
}

Advanced Topics

Take your MaleficMobile app to the next level with these advanced concepts and patterns.

Navigation

Implement multi-screen navigation using Compose Navigation or custom solutions.

Learn More

Add navigation dependency to your build.gradle.kts:

// In commonMain dependencies
implementation("org.jetbrains.androidx.navigation:navigation-compose:2.8.0")

Then implement navigation in your App:

@Composable
fun App() {
    val navController = rememberNavController()
    
    NavHost(
        navController = navController,
        startDestination = "home"
    ) {
        composable("home") {
            HomeScreen(
                onNavigateToProfile = {
                    navController.navigate("profile")
                }
            )
        }
        composable("profile") {
            ProfileScreen(
                onBackClick = {
                    navController.popBackStack()
                }
            )
        }
    }
}

State Management

Manage complex app state with ViewModels and state holders.

Learn More

Create a ViewModel for managing screen state:

class HomeViewModel : ViewModel() {
    private val _uiState = MutableStateFlow(HomeUiState())
    val uiState = _uiState.asStateFlow()
    
    fun loadData() {
        viewModelScope.launch {
            _uiState.value = _uiState.value.copy(isLoading = true)
            try {
                val data = repository.fetchData()
                _uiState.value = _uiState.value.copy(
                    isLoading = false,
                    data = data
                )
            } catch (e: Exception) {
                _uiState.value = _uiState.value.copy(
                    isLoading = false,
                    error = e.message
                )
            }
        }
    }
}

Platform-Specific Features

Access native platform APIs when needed.

Learn More

Create expect/actual declarations for platform-specific code:

// In commonMain
expect class PlatformSpecific() {
    fun getDeviceName(): String
}

// In androidMain  
actual class PlatformSpecific {
    actual fun getDeviceName(): String {
        return Build.MODEL
    }
}

// In iosMain
actual class PlatformSpecific {
    actual fun getDeviceName(): String {
        return UIDevice.currentDevice.name
    }
}
